we can install dependencies in two ways :
.Dev Dependencies : which is only used in development environment, to install this dependencies we use --save-dev flag.
                            example : npm install nodemon --save-dev
.Production Dependencies : which is used in both development and production environment, to install this dependencies we use --save flag.
                            example : npm install express --save
